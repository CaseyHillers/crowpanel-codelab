    Use a different firmware file

    Choose the complete ESP32-S3 .bin, not .app-bin or .uf2. Use a local file if your network blocks the download. Verify your board's PSRAM variant first.

    No firmware has been flashed in this session.

    After MicroPython installation finishes, unplug the ESP32’s USB cable and plug it back in. Choose Connect device, then Connect & check board. Keep USB connected while firmware is being written.
