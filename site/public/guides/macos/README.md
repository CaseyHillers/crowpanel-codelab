Supplied by Casey Hillers on October 28, 2026. These are real System Settings
screenshots. The extension-list screenshot is cropped to show only the WCH
driver row; unrelated apps and account information are excluded. The enabled
driver dialog is reproduced as supplied. No driver settings were changed while
adding these screenshots to the guide.

Labels and appearance may differ on another macOS release. The enabled switch
shows this machine's existing state, not proof that another board or host works.
