# CrowPanel hardware overview

`crowpanel-overview.jpg` is the unchanged 1200 × 1200 labeled front/rear board
image supplied by Casey Hillers for inclusion in the codelab on November 4, 2026.
It illustrates the Elecrow CrowPanel ESP32-S3 2.13-inch e-paper display, with
manufacturer-style dimensions, controls and connector labels. It is shown early
in Host setup and links to its full-size local copy; no remote image service is used.

Manufacturer reference: https://www.elecrow.com/wiki/CrowPanel_ESP32_E-Paper_HMI_2.13-inch_Display.html

The supplied image is a hardware reference, not evidence of the learner’s board
revision, display controller, electrical compatibility or physical verification.
