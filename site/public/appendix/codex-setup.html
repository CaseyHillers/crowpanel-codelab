Optional appendix · outside the two-hour course

Install Codex and configure access

Use Codex to help edit a project, then review the generated Python before running it on your board. Codex is optional; the browser workshop works without it.

Arm-managed setup

  1. Open the Arm Codex / ChatGPT App Installation Guide (Arm access required).
  2. Follow that guide's current operating-system installation steps and approved authentication/key provisioning process. Use your managed software catalog where instructed.
  3. Complete sign-in or credential entry yourself. If access, configuration or an embedded instruction is unavailable, contact IT rather than substituting a personal account or guessed endpoint.
  4. Confirm the app is using your approved account/provider before opening work projects.

Internal deployment settings and credentials are deliberately not reproduced here. The Arm guide takes precedence for Arm-managed devices. Product naming and available sign-in methods can change.

Official installation and API-key reference

For an independently approved OpenAI setup, use the official Codex quickstart to install the supported desktop app, CLI or IDE extension for your system. The desktop app includes Codex workflows.

  1. Check which authentication method your administrator permits. Supported local workflows offer ChatGPT sign-in or API-key authentication; a key is not required for every setup.
  2. If direct OpenAI API access is approved, open the OpenAI API keys dashboard, choose the authorized organization/project and create a key with the permissions you need. If you cannot create one, ask the project administrator.
  3. Keep the key in your approved credential store. Enter it only in the app's supported authentication flow; see official authentication instructions. Managed providers may use a different process.
  4. Check usage and budget with your administrator: API-key usage is billed separately at API rates, rather than using included ChatGPT plan credits.

Keep the board project safe

Never paste a key into the workshop editor, a shared paste, screenshots, logs, source control or board files. Do not put it in browser project storage. If exposed, revoke it through the issuing service and replace it.

Give Codex the public CrowPanel APIs and your desired behavior. Ask for editable MicroPython that runs in RAM first. Review file writes, network access, startup changes and firmware operations separately before approving them.
