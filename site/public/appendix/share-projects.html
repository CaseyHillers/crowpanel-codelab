Share projects with p.arm.com

Give another workshop learner a link to your project so they can copy it, edit it and try it on their own board.

Prepare a shareable copy

  1. Download your Python project from the workshop editor and keep a local copy.
  2. Remove Wi-Fi passwords, API keys, personal information and device identifiers. Use placeholders or the public workshop network settings instead.
  3. Add a short description: what it does, which board/controller it needs, required workshop libraries, and how the buttons work. State whether it runs in RAM or starts as main.py.

Paste and share

  1. Open p.arm.com (opens in a new tab) using your approved Arm access.
  2. Paste the sanitized source, give it a descriptive title if the service offers one, and create the paste using the site's controls.
  3. Check the access and expiry options shown by the service, then copy its share link and send it to your intended recipients.
  4. Ask the recipient to open the link using their approved access, copy the Python into the workshop editor, review it, and choose Run in RAM.

p.arm.com is an Arm service; access may require the corporate network or authentication. This public codelab does not grant access or guarantee a paste's visibility or retention. Follow Arm's sharing policy. The service's current UI could not be verified from this public documentation environment.

Help others reproduce it

Include any required supporting files or links to their public sources. A single pasted script does not automatically include images, certificates or libraries. Never share a full flash backup through a paste: it can contain credentials and private device data.
